# 🎨 Photoshop Advanced MacroPad Controller (AHK)

Мощный скрипт автоматизации для **12-клавишного макропада с 3 двухрежимными энкодерами**, оптимизированный для концепт-художников, ретушеров и 2D-дизайнеров в Adobe Photoshop. 

Скрипт полностью берет на себя управление параметрами кисти, навигацию по цвету и вывод интерактивного HUD-интерфейса, минуя стандартные громоздкие панели Photoshop.

---

## 🚀 Основные фишки и логика работы

### 1. Двухрежимные умные энкодеры
Каждая ручка макропада переключает режимы по нажатию (клик на энкодер) и выводит текущий статус на экран:
*   **Ручка 1:** Тон (изменение Hue) / Непрозрачность кисти (шаг 10% через горячие клавиши `1`-`0`).
*   **Ручка 2:** Насыщенность (Saturation) / Жесткость кисти (шаг 25% через `Shift + [/]`).
*   **Ручка 3:** Яркость (Brightness) / Визуальный размер кисти.
*   *Особенность:* Для Тона, Насыщенности и Яркости используется **накопительный буфер с таймером в 120 мс**. Вы можете крутить ручку как угодно быстро — скрипт плавно соберет все шаги в один пакет и отправит в Photoshop без микролагов.

### 2. Интерактивная пипетка (Цветовой Паспорт)
Умный перехват цвета при работе с инструментом `Alt + LButton`:
*   **Этап 1 (Зажатие Alt):** Скрипт мгновенно фиксирует исходный цвет («Было»).
*   **Этап 2 (Клик мышью):** Считывается новый цвет («Стало»), вычисляется дельта-сдвиг и выводится 3-строчный HUD:
    1.  *Строка 1:* Текстовое название цвета (умный анализатор на 16 полутонов, например: `Пастельный бирюзовый`, `Темно-терракотовый`).
    2.  *Строка 2:* Значения HSB, переведенные в **жирный шрифт Юникода**, с индикаторами дельты (`▲` / `▼` / `=`).
    3.  *Строка 3:* Физический RGB-паспорт цвета `[R, G, B]`.

### 3. Сквозная синхронизация инструментов (Клавиатура + Стилус)
Полная синхронизация состояния инструментов в реальном времени. Скрипт перехватывает нажатия на клавиатуре (`B`, `E`) и специальную кнопку на пере стилуса (`Ctrl + Alt + Shift + K`):
*   При переключении на **Кисть** или **Ластик** скрипт мгновенно считывает актуальные индексы непрозрачности и жесткости.
*   Выводится информативное оверлей-окно (HUD) с иконкой инструмента и его текущими параметрами, предотвращая рисование «вслепую».

### 4. Визуальный HUD (Всплывающие подсказки)
*   Все изменения параметров (размер, жесткость, цвет) сопровождаются текстовыми оверлеями (`ToolTip`).
*   Для размера кисти генерируется текстовый прогресс-бар: `РАЗМЕР: [|||||               ]`.
*   Время удержания подсказок на экране — **2 секунды**, после чего они автоматически и бесследно исчезают, не засоряя рабочую область.

## 🛠️ Системные требования и зависимости

*   **Версия AutoHotkey:** Строго **AHK v1.1 (Unicode)**. Скрипт использует специфические функции `Chr()` для генерации жирных цифр Юникода, поэтому `ANSI`-версии будут отображать иероглифы.
*   **Версия Photoshop:** Любая современная версия с поддержкой COM-объектов (`Photoshop.Application`).
*   **Кодировка файла:** При редактировании скрипта в VS Code обязательно сохраняйте файл в кодировке **`UTF-8 с BOM`**, иначе сломаются эмодзи и спецсимволы в HUD.

## 💻 Установка и запуск

1. Установите [AutoHotkey v1.1](https://autohotkey.com).
2. Скачайте файл скрипта `Photoshop_MacroPad.ahk` из этого репозитория.
3. Настройте ваш макропад (через VIA, QMK или родной софт) на отправку следующих клавиш при вращении и кликах:
   * **Энкодер 1:** Клик = `F20`, Лево = `F13`, Право = `F14`
   * **Энкодер 2:** Клик = `F21`, Лево = `F15`, Право = `F16`
   * **Энкодер 3:** Клик = `F19`, Лево = `F17`, Право = `F18`
4. Запустите скрипт. 

> ⚠️ **Важно:** Скрипт автоматически запрашивает **Права Администратора** при старте. Это необходимо для того, чтобы AutoHotkey мог перехватывать клавиши и отправлять команды в Photoshop, когда окно графического редактора находится в фокусе. Нажмите «Да» в появившемся окне UAC Windows.

## 🔧 Кастомизация под себя
Вы можете легко изменить шаг изменения параметров цвета или время отклика буфера. Для этого откройте скрипт в VS Code и измените значения таймеров (по умолчанию `-120`) или шаг буфера (по умолчанию `2` единицы) в блоках обработки клавиш `F13-F18`.

## 📝 История изменений (Changelog)

### [v2.4] — Текущая стабильная версия
*   **Добавлено:** Полная синхронизация инструментов Кисть/Ластик при нажатии на клавиатуре (`B`, `E`) и на пере стилуса (`^!+k`).
*   **Добавлено:** Автоматический запрос прав Администратора (`*RunAs`) при старте скрипта для гарантированного перехвата клавиш в окне Photoshop.
*   **Улучшено:** Внедрен режим `Critical` для функций синхронизации инструментов. Это полностью устранило микролаги и заикания HUD при быстром переключении.

### [v2.0] — Переход на COM-интеграцию
*   **Архитектурный сдвиг:** Полный отказ от эмуляции кликов мыши при выборе цвета. Скрипт переведен на прямое управление палитрой Photoshop через COM-объекты (`ComObjActive`).
*   **Добавлено:** Двухэтапная интерактивная пипетка цвета (`Alt + LButton`) с выводом «Было/Стало», дельта-сдвигов (`▲`/`▼`) и генерацией RGB-паспорта.
*   **Добавлено:** Умный текстовый анализатор цвета `ParseExtendedColor` на 16 полутонов с распознаванием пастельных и темных оттенков.
*   **Добавлено:** Функция `ToBold` для динамического перевода цифр HSB в полужирный Юникод-шрифт (`𝟬-𝟵`) для лучшей читаемости HUD.

### [v1.5] — Оптимизация энкодеров
*   **Добавлено:** Накопительный буфер с таймером на **120 мс** для Тона, Насыщенности и Яркости. Ручки можно крутить с любой скоростью — Photoshop больше не зависает.
*   **Добавлено:** Текстовая шкала-прогрессбар `[|||||     ]` для визуального контроля размера кисти в реальном времени.

### [v1.0] — Базовый релиз
*   Первая рабочая версия скрипта. Настройка двухрежимной работы 3 энкодеров и базовых всплывающих подсказок ToolTip.
